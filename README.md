# MANU OS

Asistente privado de Manu para capturar una vez, organizar y recuperar información cuando sea útil. La vía de uso documentada actual es una **PWA en `web/`**; el trabajo nativo Swift está separado y pausado según `ai/PROJECT_STATE.md` y ADR-0012.

**El repositorio GitHub es público.** Que el asistente sea privado no permite guardar aquí vaults, memoria personal, conversaciones, datos de clientes, terceros ni credenciales.

La referencia de estado leída para esta portada es del 24/11/2026: WEB-124 describe el centro de operaciones en escritorio y deja pendientes Safari real y aprobación visual. Consultar siempre el estado actual, sin convertir lo implementado en verificado en dispositivo.

La antigua portada de BRAIN-00 afirmaba «producto aún no implementado». Se conserva como [antecedente](docs/archive/README-BRAIN-00.md), no como estado vigente. Los documentos nativos antiguos se interpretan con sus ADR posteriores; no reactivan esa línea de desarrollo.

Esta actualización es documental: no cambia app, servicios, datos, permisos, despliegues ni resultados de pruebas.
